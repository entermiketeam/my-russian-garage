# Mein Garagen-Sommer 3D — ВАЗ 2102 в Германии

Аналог *My Winter Car* на Python. Октябрь 1998 года, городок Kleinbruck в Нижней Саксонии.
У вас есть однокомнатная квартира и ржавая ВАЗ 2102 1979 года, которая шесть лет простояла в гараже.

Игра трёхмерная (движок **Ursina / Panda3D**): вид от первого лица, вождение из салона или с камерой сзади.
Старая 2D-версия с видом сверху тоже осталась (`main2d.py`), но в ней есть только ВАЗ, цель с AE86 доступна только в 3D.

## Запуск

```bash
make install    # или: pip3 install -r requirements.txt
make run        # 3D-версия (python3 main.py)
make run2d      # 2D-версия (python3 main2d.py)
```

При первом запуске звуки генерируются в папку `sounds/`, это занимает пару секунд.

## Цель

**Главная цель — купить и починить Toyota AE86** (Sprinter Trueno 1985, «панда» с поднимающимися фарами).
Она гниёт на свалке **Autoverwertung Kowalski** прямо за вашим гаражом: въезд с Hauptstraße, справа от гаража,
над воротами жёлтая вывеска. Ковальский отдаёт её **бесплатно**: деньги нужны на запчасти.

1. ВАЗ 2102 со старта на ходу, с номерами `KB-VZ 102` и TÜV до весны, но ржавый насквозь.
2. **Брошенные машины можно забрать себе.** У загородных дорог стоят брошенные машины: на карте (M) это серые точки.
   Подойдите и нажмите **E**, чтобы осмотреть машину. Видно модель, пробег, состояние, что сломано и чего нет.
   Кнопка «Забрать себе» ничего не стоит. После этого машина ваша: дотащите её тросом (**T**) к гаражу, восстанавливайте,
   пройдите TÜV, получите номера и ездите. На карте ваши находки голубые. Ненужную можно сдать на лом
   у пресса Ковальского (35–120 DM). Свою машину на лом сдать можно только после подтверждения.
   Ещё работа: склад (Lager) и доставка пиццы.
   **Заброшенные гаражи и сараи** (6 штук, на карте это коричневые квадраты): у ворот нажмите E, чтобы открыть.
   Часть ворот заперта, для них нужна монтировка (12 DM, Ost-Autoteile или заправка). Внутри забытая машина:
   она стояла под крышей, поэтому ржавчины меньше, но пыль, спущенные шины и сухой аккумулятор. Её тоже можно
   забрать бесплатно. На полках детали для неё и инструменты (E — обыскать, один раз).
3. Купите AE86 у Ковальского: подойдите к ней на свалке и нажмите E, или зайдите в контору.
   Она очень ржавая: пороги в дырах, одно колесо на кирпичах, нет АКБ и глушителя, ремень ГРМ вот-вот порвётся.
4. Затащите её на тросе в гараж: трос от «двойки», T у AE86. Или вызовите эвакуатор по телефону.
   Японские запчасти продаёт Autohaus Krüger (Toyota) в восточном конце Hauptstraße. Первым делом меняйте ремень ГРМ.
5. Сварите пороги и днище, пройдите **TÜV**, поставьте AE86 на учёт в **Rathaus** (`KB-AE 86`). Это победа.

Квартира ваша собственная: квартплаты нет, выселить не могут. На старте новой игры — 3000 DM.
Страховка — 24 DM за каждую машину на учёте, списывается каждые 7 дней.
Если с героем что-то случится (авария, истощение), он бесплатно очнётся дома — деньги не списываются.

## Дальность прорисовки

Карта существует целиком, но рисуется и обсчитывается только область вокруг игрока. Настройки — в `config.py`:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `VIEW_DIST` | 320 м | дальше этого город, снег, вывески выключаются; туман к этой границе растворяет всё в цвете неба |
| `CHUNK` | 100 м | размер квадратов, на которые нарезана карта |
| `CAR_VIEW_DIST` | 140 м | ближе этого у машин подробная 3D-модель (дальше — модель выгружается, машина остаётся в мире) |
| `SIM_DIST` | 450 м | дальше этого трафик стоит на паузе |

Больше — дальше видно, но тяжелее для компьютера. Физика вашей машины, машины на тросе и всех движущихся машин
рядом не отключается никогда.

## Управление

| Пешком | |
|---|---|
| WASD + мышь | ходить и смотреть (Shift — бежать) |
| E | действие (двери, предметы в квартире, капот, доставка, сдать машину на лом) |
| G | второе действие рядом (например, «Забрать себе», если рядом стоит и своя машина) |
| T | буксировочный трос: привязать брошенную машину / свою AE86 к машине рядом, отвязать |
| R | разобрать машину на запчасти (брошенную, со свалки или свою ненужную) |
| E (прицелом) | действие с тем, на что смотрит перекрестие: открыть/закрыть дверь, сесть на сиденье, капот, багажник, открутить/затянуть болт или гайку, поставить деталь |
| G (прицелом) | снять деталь, у которой откручен весь крепёж |
| F | сесть в машину / выйти |
| Tab | руки: что держите — съесть/выпить, осмотреть, положить, поменять |
| Q / Z / X | поменять предметы между руками / положить из левой / из правой руки |
| M | карта |
| Esc | пауза: сохранить / загрузить |
| - / = | чувствительность мыши |

| За рулём | |
|---|---|
| I (держать) | стартер; нажать ещё раз — заглушить |
| C | подсос у ВАЗ (холодный мотор без него не заведётся; у AE86 впрыск — подсос не нужен) |
| W / S | газ / тормоз |
| A / D | руль |
| Пробел | сцепление (держать, иначе на остановке машина заглохнет) |
| Стрелка вниз | ручник: W + A/D + стрелка вниз на скорости — срыв в занос (дрифт) |
| E на переключателях у руля / [ и ] | левый / правый поворотник (повторно — выключить; после поворота выключается сам) |
| Shift / Ctrl | передача вверх / вниз (1–5, R — задняя, N — нейтраль) |
| L / H | фары / гудок |
| V | вид из салона / камера сзади |

Работа с машиной: подойдите к ней и нажмите **E**. Откроется капот, камера облетает машину.
Мышь с зажатой кнопкой поворачивает камеру, колесо мыши приближает. Сварка и зарядка АКБ доступны только в гараже.

## Что есть в игре

- **Зима (декабрь 1998).** Снег лежит неравномерно: на полях и газонах толстым слоем, у стен домов — надувы,
  вдоль дорог — грязные валы от снегоуборщика (с разрывами у перекрёстков и въездов), на крышах — снег с сосульками
  (на тёплых крышах подтаял), на ёлках — белые шапки. На самих дорогах снега мало, в основном у кромки.
  **Слякоть** — только на дорогах и тротуарах: мокрая, грязная каша до ~10 см. Она объёмная: колёса продавливают
  колею, по краям выдавливаются валики, следы остаются и постепенно заметаются снегопадом. В слякоти машину тормозит
  и ведёт, она проседает; на снегу меньше сцепления. Холодный мотор заводится хуже, аккумулятор на морозе слабее.
- **Два подземных гаража (Tiefgarage)** — въезды «P» у Hauptstraße (Marktplatz) и у вокзала. Заезжать можно на машине
  и заходить пешком; по пандусам — на уровень −2. У каждого уровня свой стиль (современный, низкий, старый, бункер),
  колонны с разметкой, трубы, мигающие и разбитые лампы, лужи, помещения: лестницы, техкомнаты, кладовки-клетки,
  мойка, склад, обрушенная комната, бомбоубежище. Там стоит **42 машины** — меньше ржавые, чем на улице, но с
  ржавчиной и в салоне; запчастей там меньше, чем машин (ищите в кладовках и на складе).
- **Три заброшенные парковки** (бывший Konsum-Markt, Pendlerparkplatz на L 342, двор экспедиции Müller):
  ржавые и частично разобранные машины, детали на земле (E — подобрать), тележки, покосившиеся фонари, контейнеры,
  прицепы, погрузчик, бурьян из-под снега.
- **Gebrauchtwagen Weber** (на L 342, за городом): площадка с ценниками. В конторе — список машин с пробегом,
  состоянием и ценой, можно купить. Продать свою: поставьте её на жёлтую площадку «Ankauf» и зайдите в контору.
  Находить машины бесплатно по-прежнему можно.
- **Свалка Ковальского расширена**: 16 машин-доноров разных категорий (сгнившие, битые, полуразобранные, почти целые,
  доноры). **R — разобрать**: двигатель, КПП, колёса, двери, капот, багажник, фары, сиденья и остальное попадают
  в инвентарь и ставятся на машины той же модели. Мотор и коробку без крана снимают только на свалке или в гараже.
- Новые модели: **Москвич-2140, Volvo 240, BMW E21, Audi 80 (B2), Honda Civic** — всего 11 моделей находок плюс ВАЗ и AE86.
- **Работа руками прямо на машине.** Двери открываются (E на ручке), сесть — E на сиденье, выйти — E на
  открытой двери изнутри (F тоже работает). Багажник/задняя дверь откидываются на петлях (внутри — запаска,
  домкрат, коврик). Капот открывается как раньше и остаётся открытым после меню. У каждой детали свой крепёж
  (колесо — 4–5 гаек, аккумулятор — 3, ГБЦ — 10+ болтов, поддон — 16...) — он виден на машине: E на болте
  откручивает/затягивает его, G снимает деталь, когда крепёж отпущен, E на пустом месте ставит деталь из
  инвентаря «наживлённой». Недокрученное работает плохо: колесо разбалтывается и отваливается, ГБЦ прогорает,
  поддон течёт, клемма АКБ пропадает. Меню ремонта знает о том же крепеже (строка «Крепёж: 2/4», «Затянуть»).
- **Поворотники**: подрулевые переключатели, лампы спереди/сзади/на крыльях, стрелки на щитке, щелчки,
  автоотключение после поворота. Приборы в салоне работают: спидометр, тахометр, топливо, температура.
- **Ford Mustang 1967 (289 V8)** — на площадке Weber за 8 900 DM. Комплект Shelby GT500 в Autohaus Krüger
  (10 деталей, ~38 700 DM): Big-Block 428 Cobra Jet, КПП Toploader, подвеска, тормоза, колёса 17", боковой
  выхлоп, обвес, капот с воздухозаборниками, покраска Pepper Grey с чёрными полосами, салон. Каждая деталь
  сразу меняет машину; все десять превращают её в «Ford Mustang Shelby GT500 «Eleanor»» (~358 л.с., 0–100 ≈ 5 с).
- **Двигатель «до последнего болта»** (E у машины → «Двигатель: разборка и сборка»). У каждого мотора своя раскладка:
  ГБЦ, прокладка ГБЦ, поршни с кольцами, шатуны, шатунные и коренные вкладыши, коленвал, распредвал(ы), клапаны,
  клапанные пружины, масляный поддон, масляный насос, масляный фильтр, помпа, термостат, шкив коленвала, крышка ГРМ,
  цепь или ремень ГРМ с натяжителем, впускной и выпускной коллекторы, топливная рампа (впрыск) или трубки ТНВД (дизель).
  У двухтактных Trabant и Wartburg — свои (без клапанов и ГРМ). Навесное (генератор, стартер, карбюратор, свечи,
  трамблёр, радиатор) — как раньше, в «Деталях».
  - Порядок как в жизни: к ГБЦ не добраться, пока стоят клапанная крышка, ГРМ и коллекторы; к коленвалу — пока не
    сняты поддон, шатуны, насос, ГРМ, КПП и сцепление. Меню подсказывает, что мешает; есть «Снять всё мешающее»,
    «Разобрать полностью» и «Собрать из деталей в инвентаре».
  - У каждой детали своё состояние, своя цена в магазине запчастей (для каждой модели) и своя 3D-модель в моторном
    отсеке: сняли клапанную крышку — видно распредвал, сняли ГБЦ — видно поршни.
  - Осмотр: Tab → деталь → «осмотреть» (задиры, прогар, «стёрты до меди», вердикт). «Диагностика двигателя» —
    компрессия по цилиндрам и давление масла с подсказками (прокладка, клапан, кольца, фазы).
  - Состояние деталей определяет работу мотора: компрессию и мощность, давление масла, стук вкладышей, перегрев,
    уход антифриза. Ошибки сборки: ГРМ «на глаз» — мотор троит, а у клапанобойных (AE86, Civic, Audi, W123) гнёт
    клапаны; ГБЦ «на глаз» — быстро прогорает прокладка; старая прокладка ГБЦ течёт; без масляного насоса нет давления.
  - Двигатель можно снять целиком — внутренности уезжают вместе с ним. Доноров на свалке тоже можно разбирать до
    поршней.
- **Ремонт снизу — лёжа под машиной** (`underside.py`, `under3d.py`, `under_play.py`). Детали низа — масляный
  поддон и низ двигателя (масляный насос, вкладыши, шатуны, коленвал), КПП, сцепление, выхлоп, амортизаторы, рулевые
  тяги, стартер — снимаются, ставятся и затягиваются **только из-под машины**; моторный отсек — только сверху, у
  открытого капота (из-под машины до аккумулятора не дотянуться). Масло сливают снизу (пробка в поддоне), заливают сверху.
  Это касается и болтов в мире, и меню работ (там у таких деталей пометка «· снизу»); «Разобрать полностью» снимает всё,
  что доступно с того места, где вы, и подсказывает, что осталось сделать с другой стороны.
  - **Лечь под машину:** посмотрите на низ порога своей машины — E «Лечь под машину». Под машиной: WASD — ползти
    (сквозь колёса и туда, где низко, не пролезть), мышь — смотреть на днище, E/G — болты и детали снизу (как сверху,
    но на длину руки), «Работы снизу — меню», F — вылезти (выползти можно и самому — из-под любого борта). Снизу светит
    переноска; двигатель снизу видно и при закрытом капоте.
  - **Просвет решает:** машина на колёсах — около 17–18 см: пролезают только голова и плечи у порога, мелкий крепёж и
    слив масла — можно, а КПП, сцепление, коленвал, выхлоп так не снять. Ниже 13 см (спущенные колёса, занижение,
    слякоть) — не пролезть совсем.
  - **Домкрат и подставки** (Ost-Autoteile, Autohaus Krüger → расходники): домкрат (59 DM) поднимает перёд или зад на
    30 см — E на точке подъёма внизу бампера; там же — «Поставить на подставки» (29 DM пара), домкрат освобождается
    для другой стороны. На двух парах подставок машина стоит ровно, просвет ~46 см — можно всё. Снять с подставок —
    снова нужен домкрат. Подъём — и в меню работ («Подъём машины»). Поднятая машина не едет (колёса в воздухе).
  - **Не лежите под машиной на одном домкрате:** во время работы он может соскочить — машина падает, вы сильно
    ушибаетесь (−45 здоровья), домкрат мнётся.
- **Ремонт где угодно.** Двигатель, сцепление и кузов чинятся там, где стоит машина (гараж не нужен).
  Вмятины после аварий и даже «тотал» выправляются без сварки и металла — домкратом, цепью и кувалдой, дольше;
  со сваркой и листами металла — быстрее. После рихтовки геометрия, двери/капот/багажник и увод — в норме, TÜV
  претензий к аварии не имеет. Гниль тоже можно залатать без сварки (выколотка, холодная сварка).
- **Дрифт.** На скорости держите W + A или D и дёрните ручник (стрелка вниз), затем отпустите его и держите занос
  газом и контррулём. Физика с боковым скольжением: шины с кругом трения (тяга и поворот делят одно сцепление),
  пробуксовка ведущих колёс, перенос веса, самовыравнивание передних колёс в заносе. Задний привод (ВАЗ, BMW E21,
  Civic, AE86) срывается газом и держит угол; передний привод даёт короткий занос от ручника и сам выравнивается;
  полный привод (поддерживается физикой) заносит, но вытягивает сам. На снегу и слякоти всё легче, на сухом
  асфальте слабому ВАЗу мощности на силовой занос не хватает. На приборах — «ЗАНОС 35°».
- **Аварии и деформация кузова.** Кузов сминается там, куда пришёлся удар: спереди — бампер, «гармошка» и капот
  домиком, крылья в складки; сбоку — вдавленные двери; сзади — багажник и бампер. Форма зависит от скорости, угла,
  препятствия (столб входит глубоко и узко, стена — широко, другая машина — на уровне бампера) и у каждой аварии своя.
  При сильном ударе бампер висит на одном креплении, погнутая подвеска уводит машину. Ломаются радиатор, фары,
  двери, мотор, рулевое; TÜV не пропустит битую машину. Рихтовка — в гараже (сварка + листы металла, меню «Кузов»).
  После очень тяжёлой аварии — Totalschaden: своими руками не выправить, стапель у Krüger стоит 2800 DM —
  обычно дешевле сдать машину на лом. На свалке у Ковальского стоят битые машины с настоящими вмятинами.
- **Honda Civic 1.5 GL (1985)**: мотор EW 1.5 12V 85 л.с., 5-ступенчатая КПП, 850 кг, 0–100 примерно за 9,5 с. В игре Civic заднеприводный (переделан под дрифт).
  Встречается редко, но где угодно: у жилых домов, у дорог, в подземных гаражах, на заброшенных парковках, на свалке,
  в заброшенных гаражах, на площадке Weber. Иногда прошлый хозяин уже поставил турбину.
- **Тюнинг (турбонаддув для Civic)**: E у машины → «Тюнинг». Детали продаёт Autohaus Krüger (в списке запчастей Civic):

## Файлы

| Файл | Что внутри |
|---|---|
| `main.py` | 3D-игра: камера, ходьба, вождение, режимы |
| `state.py`, `actions.py` | логика: время, потребности, деньги, здания, работа, ремонт |
| `car.py` | физика, износ и внешний вид всех машин |
| `models.py` | модели брошенных машин: характеристики, кузов, детали |
| `world.py` | карта города (общая) |
| `places.py`, `places3d.py` | подземные гаражи, парковки, площадка Weber: раскладка и 3D |
| `winter.py`, `winter3d.py` | снег и слякоть: логика (колеи, сцепление) и 3D |
| `engine.py` | двигатель по деталям: раскладки, порядок разборки, влияние на работу, осмотр, диагностика |
| `fasteners.py` | болты и гайки деталей, что бывает с недокрученным |
| `car3d_extra.py` | двери, багажник, поворотники, приборы, детали салона/кузова, болты в 3D, точки для прицела |
| `damage.py` | аварии: вмятины, деформация кузова, последствия, «тотал» |
| `streaming.py` | подгрузка мира вокруг игрока (квадраты карты по дальности) |
| `electrics.py` | электрика: блок предохранителей, цепи, неисправности, прозвонка, последствия (полиция, TÜV) |
| `storage.py` | хранилища предметов: багажник, холодильник, стеллаж в гараже |
| `hands3d.py` | руки игрока в 3D: предметы в руках, анимации еды и питья |
| `underside.py`, `under3d.py`, `under_play.py` | ремонт снизу: просвет, домкрат и подставки, детали низа и их болты, игрок под машиной |
| `window_views.py` | вид из окон квартиры на настоящий город (камеры по сторонам дома, стекло, блики, осадки) |
| `window_views.py` | вид из окон квартиры на настоящий город (камеры по сторонам дома, стекло, блики, осадки) |
| `tires.py` | шины: протектор, давление, сцепление по покрытию/погоде, износ, проколы |
| `traffic.py`, `traffic3d.py` | трафик на физике, светофоры, уличные гонщики, пешеходы; их 3D с уровнями детализации |
| `service.py`, `service3d.py` | автосервис и бессрочная гарантия; здание, механики |
| `mirrors.py` | рабочие зеркала заднего вида (камеры назад, отражение на стекле) |
| `keys.py`, `theft.py` | ключи и замки; угон, полиция, объявления, вознаграждение |
